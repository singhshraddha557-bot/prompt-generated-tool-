# Free AI Prompt Generator Tool 🚀

 https://claude.ai/public/artifacts/b5241f53-f2d1-4a38-8556-f26ed08dd4ff

A **free, open-source tool** to supercharge your AI workflows by generating high-quality, customized prompts for models like GPT, Claude, or Llama. This user-friendly web app (built with no-code/low-code tools) helps you craft prompts that boost accuracy, creativity, and efficiency—perfect for data scientists, writers, developers, and AI enthusiasts.

Whether you're annotating datasets, automating audits, or building ML pipelines (like my freelance projects in AI data quality), this tool saves hours of trial-and-error. No coding required—just point, click, and generate!

> **Why this tool?** In my 5+ years of AI data automation, I've seen how a bad prompt tanks model performance (e.g., dropping F1 scores by 15%). This generator fixes that with templates tuned for real-world use cases.

## ✨ Features
- **Smart Templates:** Pre-built for 10+ categories (e.g., creative writing, code generation, data analysis, ethical AI queries).
- **Customization Engine:** Input your context, tone, length, and constraints—outputs optimized prompts in seconds.
- **Local & Offline Mode:** Download and run via browser; no cloud dependencies or costs.
- **Integration Ready:** Export prompts for ChatGPT, Jupyter notebooks, or VS Code extensions.
- **Analytics Lite:** Tracks prompt variations and suggests improvements based on best practices.
- **Extensible:** Easy to add your own templates or integrate with libraries like Hugging Face.

## 🛠️ Quick Start

### Prerequisites
- Modern web browser (Chrome, Firefox, etc.)

### Installation
1. Clone the repo:
   ```
   git clone https://github.com/sharddha-singh/ai-prompt-generator.git
   cd ai-prompt-generator
   ```
2. Open `index.html` in your browser (or use the hosted demo link below).
3. No dependencies—runs standalone!

Hosted Demo:  https://drive.google.com/drive/folders/1_sXVeT_BqUWnHYlNSrr_FOdz3TPvLSe9?usp=sharing

### Usage
Select category, fill in details, and hit "Generate." Here's how:

**Example for Data Analysis:**
- Category: data-analysis
- Context: "Sales data from Q4 2025"
- Tone: professional
- Length: medium

**Output Example:**
"As a senior data analyst with expertise in Python and SQL, analyze the provided Q4 2025 sales dataset. Focus on key trends, anomalies, and actionable insights. Use visualizations like bar charts for comparisons. Structure your response: 1) Summary stats, 2) Visual recommendations, 3) 3 top recommendations. Dataset: [Insert CSV here]. Keep it concise yet detailed."

For advanced use, edit the JSON config file to add custom templates.

## 📝 Examples

### Creative Writing
**Input:** Category: storytelling, Context: "A robot discovering emotions in a futuristic city"  
**Output:** "You are a master storyteller in the vein of Isaac Asimov. Craft a 500-word short story about a sentient robot awakening to human emotions amid neon-lit skyscrapers in 2147. Include sensory details, internal conflict, and a twist ending. Avoid clichés; emphasize themes of isolation and connection."

### ML Annotation
**Input:** Category: ai-annotation, Context: "Labeling images for object detection"  
**Output:** "Act as an expert ML annotator. Review this batch of 50 images for a YOLOv8 object detection model. Guidelines: Bounding boxes must be tight (IoU >0.8), labels from {car, pedestrian, traffic light}. Flag ambiguities for review. Output format: JSON array with image_id, bbox_coords, label. Prioritize edge cases like occlusions."
